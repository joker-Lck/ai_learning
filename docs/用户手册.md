## 1. 系统概述

本系统是一个面向高等教育场景的**AI 个性化学习资源平台**，基于 MiMo 大模型驱动，通过 6 个专业智能体（画像师、讲师、导师、辅导员、评估师、协调器）协同工作，为学生提供以下核心能力：

| 能力 | 说明 |
|------|------|
| 学生画像构建 | 9 维度动态画像，精准刻画学习特征 |
| 个性化资源生成 | 7 种资源类型，含 AI 生成视频、动画、图片等多模态内容 |
| 智能辅导答疑 | 24/7 多轮对话，支持记忆增强和知识库检索 |
| 在线做题 | 3 种练习模式，AI 自适应出题 + 错题重练 + 薄弱点专练 |
| 学情分析 | 多维度数据统计、趋势图表、周报自动生成 |
| 学习路径规划 | 基于当前水平自动规划最优学习路径 |
| 效果评估报告 | 多维度量化评估，可视化展示学习成效 |
| 知识库管理 | 文档上传 + 混合检索引擎（关键词 + 语义 + 融合排序） |

## 2. 安装与启动

### 2.1 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.14 | 后端运行环境 |
| Node.js | 18+ | 前端构建环境 |
| npm | 9+ | 前端包管理 |
| MiMo API Key | — | 从 MiMo 开放平台获取 |

### 2.2 一键启动（推荐）

1. 双击项目根目录下的 `启动.bat` 文件。
2. 系统将自动完成以下步骤：
   - 检查 `.env` 配置文件
   - 初始化 SQLite 数据库（9 个独立数据库）
   - 启动后端服务（端口 8000）
   - 启动前端服务（端口 3000）
   - 自动打开浏览器访问系统

### 2.3 手动启动

```bash
# 终端 1 — 启动后端
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

# 终端 2 — 启动前端
cd frontend && npm run dev
```

### 2.4 访问地址

| 服务 | 地址 |
|------|------|
| Web 前端 | http://localhost:3000 |
| API 文档（Swagger） | http://localhost:8000/docs |
| API 文档（ReDoc） | http://localhost:8000/redoc |

## 3. 账号与登录

### 3.1 登录

1. 打开浏览器访问 `http://localhost:3000`，进入登录页面。
2. 输入用户名和密码，点击「登录」按钮。
3. 登录成功后自动跳转到首页工作台。

> **默认管理员账号**：用户名 `admin`，密码 `admin123`

### 3.2 注册

1. 在登录页面切换到「注册」选项卡。
2. 填写用户名、密码和确认密码。
3. 点击「注册」按钮完成注册。
4. 注册成功后切换到登录页面，使用新账号登录。

### 3.3 游客模式

在登录页面点击「游客体验」，可以无需注册直接体验系统功能。游客模式下部分功能（如资源生成、在线做题）需登录后使用。

## 4. 首页工作台

登录后进入系统，首页为全屏展示页面，向下滚动（或点击「进入学习看板」按钮）进入工作台。

### 4.1 首页（Hero 页）

展示系统概况：
- 系统标题与定位说明
- 4 个核心数据指标（智能体数量、资源类型数、画像维度数、数据库数量）
- 「进入学习看板」按钮

### 4.2 工作台

工作台是所有功能模块的入口，点击模块卡片即可展开对应的功能界面。包含以下区域和模块入口：

| 入口 | 对应模块 | 说明 |
|------|---------|------|
| 学生画像 | ProfileModule | 9 维度画像构建与管理 |
| 学习资源 | ResourcesModule | AI 资源生成 + 视频资源 + 图书资源 |
| 学习路径 | PathModule | 学习路径规划与学习计划 |
| 智能辅导 | TutorModule | AI 多轮对话答疑 |
| 效果评估 | AssessmentModule | 多维度学习评估 |
| 知识库 | RagKnowledgeModule | 文档上传与混合检索 |
| **在线做题** | **QuizModule** | **AI 出题 + 错题重练** |
| **学情分析** | **AnalyticsModule** | **数据统计与趋势图表** |
| 协同动态 | CollaborationModule | 智能体活动日志 |

每个模块以**全屏覆盖层**的形式从工作台展开，点击左上角「返回工作台」或按 `ESC` 键关闭。

### 4.3 页面导航

- **鼠标滚轮**：上下滚动切换首页和工作台
- **键盘**：`↑`/`↓` / `PageUp` / `PageDown` 切换页面
- **页面右侧指示器**：点击圆点切换页面
- **触摸滑动**：移动端支持上下滑动切换

## 5. 模块一：学习资源生成（详细）

学习资源模块是系统的核心生产模块，利用 MiMo 大模型根据个人画像和学习需求，自动生成多种类型的个性化学习资源。资源生成支持**实时流式输出（SSE）**，并可生成视频、动画、图片等多模态媒体内容。

### 5.1 进入学习资源模块

在工作台点击「学习资源」卡片进入。

### 5.2 界面布局 — 三个标签页

学习资源模块包含三个独立的标签页，通过顶部标签切换：

| 标签页 | 功能 |
|--------|------|
| **AI 资源生成** | 基于 MiMo 大模型个性化生成 7 种类型的学习资源 |
| **视频资源** | 搜索和浏览 Bilibili 教学视频 |
| **图书资源** | 搜索和浏览国家图书馆 / 鸠摩搜书的图书 |

### 5.3 AI 资源生成（完整流程）

#### 第一步：配置生成参数

**① 学科输入**

在「学科」输入框中输入当前学习的学科名称，例如：
- 高等数学、线性代数、概率统计
- Python、Java、C++
- 数据结构与算法、机器学习、深度学习
- 计算机网络、操作系统、数据库

> 系统会根据输入的学科**智能推荐资源类型**。例如输入「Python」会自动勾选代码、文档、题库；输入「高等数学」会自动勾选文档、题库、思维导图。

**② 主题输入**

在「主题」输入框中输入具体的学习主题，例如：
- "二重积分的计算方法"
- "Python 列表推导式"
- "卷积神经网络的工作原理"
- "Dijkstra 最短路径算法"

> 建议：主题越具体，生成的资源越精准。避免输入过于宽泛的主题如"数学"。

**③ 资源类型选择**

从 7 种资源类型中选择需要生成的类型（可多选，按钮式选择）：

| 类型 | 说明 | 生成内容 |
|------|------|---------|
| 文档 | 结构化学习文档 | Markdown 格式知识讲解，含章节、关键点、参考资料 |
| 思维导图 | 知识结构图 | Mermaid.js 渲染的思维导图，可生成 SVG 图片 |
| 题库 | 练习题目 | 选择题/填空题/判断题，含答案和详细解析 |
| 视频 | 教学视频 | **AI 生成教学视频**（MP4），含多场景画面与配音脚本 |
| 动画 | 交互动画 | **AI 生成 SVG 动画**（HTML），可交互播放 |
| 代码 | 代码案例 | 带注释的代码示例，支持多种编程语言 |
| 阅读 | 扩展阅读 | 扩展阅读材料与参考书目推荐 |

> **多模态内容说明**：视频类型资源会调用 MiMo 图片生成模型逐场景生成画面，再合成 MP4 视频文件；动画类型资源会生成可交互的 SVG 动画页面；思维导图会生成 SVG 图片。这些媒体内容可在资源卡片中直接预览和全屏播放。

**④ 难度级别**

选择适合当前水平的难度（下拉选择框）：

| 难度 | 适用对象 |
|------|---------|
| 初级 | 初学者，从基础概念讲起 |
| 中级 | 有一定基础，适度深入 |
| 高级 | 基础扎实，深度剖析 |

> 系统会自动参考学生画像（知识基础、技能水平等）调整生成内容的深度。

#### 第二步：开始生成

确认参数配置无误后，点击底部的「开始生成资源」按钮。

> 按钮在未选择任何资源类型时为禁用状态（灰色）。

#### 第三步：观察生成进度

生成过程中，页面会实时展示以下信息：

**进度条**：顶部显示整体进度百分比和当前正在生成的资源类型名称。

**多阶段进度条**：以彩色分段条的形式展示每种资源类型的生成状态：
- 绿色（已完成）
- 紫色脉冲（正在生成）
- 灰色（等待中）

**骨架屏**：未生成的资源以动画骨架占位的形式预展示。

**生成计数器**：按钮区域显示「生成中... 已完成/总数」。

#### 第四步：查看和使用生成的资源

资源生成完成后，以卡片列表的形式展示在页面下方。每个资源卡片包含：

**卡片头部信息**：
- 资源类型图标（不同颜色区分类型）
- 资源标题
- 资源类型标签
- 媒体标签（如「AI生成视频」「AI生成动画」「SVG思维导图」「AI生成图片」）
- 展开/收起按钮
- 全屏打开按钮（有媒体内容时显示）
- **导出按钮**（点击可将资源导出为文件下载）
- 完成状态图标

**展开后的内容区域**：

根据资源类型，展开后展示不同的内容：

| 类型 | 展示内容 |
|------|---------|
| 文档 | Markdown 渲染的结构化文档（标题、列表、段落） |
| 思维导图 | SVG 思维导图图片 + Markdown 文本描述 |
| 题库 | 题目列表，含选项、答案和解析 |
| 视频 | **MP4 视频播放器**（自动播放，带控件）+ 视频脚本文本 |
| 动画 | **SVG 动画 iframe 内嵌播放**（可在页面内直接交互） |
| 代码 | 带语法高亮的代码块 + 关键点说明 |
| 阅读 | 分章节的扩展阅读材料 |

> **导出功能**：点击「导出」按钮，系统会将资源导出为文件（文档/题库 → Word 文档，思维导图/动画/视频 → 原始媒体文件），自动下载到本地。

### 5.4 视频资源（Bilibili）

视频资源标签页集成了 Bilibili 视频搜索功能。

#### 搜索功能

1. 在搜索框中输入关键词，如「Python 入门教程」。
2. 点击搜索按钮或按回车键。
3. 也可以点击页面上的**热门搜索标签**快速搜索。

#### 高级筛选

搜索结果支持以下筛选和排序：

| 筛选项 | 选项 |
|--------|------|
| 排序方式 | 综合排序 / 最多播放 / 最新发布 / 最多弹幕 |
| 时长筛选 | 全部时长 / 5分钟以下 / 5~30分钟 / 30~60分钟 / 60分钟以上 |

#### 分类浏览

页面提供学科分类浏览，点击分类标签直接查看推荐视频：

深度学习、Python、RAG 与 Agent、计算机视觉、前端开发、数据分析

#### 视频卡片信息

每个视频卡片展示：
- 封面图（通过后端代理加载，避免跨域问题）
- 视频标题（支持富文本）
- 作者名称
- 播放量（自动格式化，如「12.5万」）
- 弹幕数
- 视频时长
- 发布时间（相对时间，如「3天前」）
- 关联标签

点击视频卡片跳转到 Bilibili 观看完整视频。

#### 分页浏览

搜索结果支持分页展示，底部有上一页/下一页翻页按钮。

> **行为追踪**：系统会记录用户观看的视频类型，用于完善学生画像和优化学习推荐。

### 5.5 图书资源（国家图书馆 + 鸠摩搜书）

图书资源标签页集成了国家数字图书馆和鸠摩搜书的图书搜索功能。

#### 分类浏览

图书资源按以下分类展示推荐书目：

| 分类 | 内容 |

| NLP | 自然语言处理、文本分析 |
| 大模型 | LLM、Prompt Engineering、RAG |
| 计算机科学 | 算法、数据结构、操作系统 |
| 数据分析 | 统计学、数据挖掘、可视化 |

每个图书卡片展示：

## 6. 模块二：在线做题（详细）

在线做题模块是系统的核心练习模块，支持 AI 自动生成题目、针对薄弱知识点出题、以及错题重练巩固记忆。模块提供完整的答题流程、实时计分、答题统计和历史记录功能。

### 6.1 进入在线做题模块

在工作台点击「在线做题」卡片进入。

### 6.2 界面布局

模块顶部为标题栏，包含：
- 模块标题「在线做题」
- 「返回」按钮（答题过程中可用）
- 「历史」按钮（查看答题历史记录）
- 「统计」按钮（查看做题统计数据）

主体区域根据当前视图（开始/答题/结果/历史/统计）展示不同内容。

### 6.3 开始做题 — 配置面板（完整流程）

#### 第一步：选择练习模式

系统提供 3 种练习模式：

| 模式 | 图标 | 说明 | 适用场景 |
|------|------|------|---------|
| **普通练习** | 📝 | AI 根据学科和知识点自动生成题目 | 日常练习、新知识巩固 |
| **薄弱点专练** | 🎯 | AI 分析薄弱知识点，针对性生成题目 | 薄弱环节强化 |
| **错题重练** | 🔄 | 选择历史错题重新练习，基于遗忘曲线调度 | 巩固记忆、考前复习 |

#### 第二步：选择学科

页面提供 9 个常用学科的快捷按钮：

`数学` `英语` `Python` `数据结构` `机器学习` `深度学习` `计算机网络` `操作系统` `数据库`

点击选中（高亮显示），再次点击取消选中。也可以不选学科，直接输入知识点。

#### 第三步：输入知识点（可选）

在「或输入具体知识点」输入框中输入具体的练习主题，例如：
- "二重积分换元法"
- "Python 装饰器"
- "二叉树的遍历方式"

> 普通练习和薄弱点专练模式下可用。错题重练模式下此输入框隐藏。

#### 第四步：设置题目数量

选择每次练习的题目数量（普通练习和薄弱点专练模式下可用）：

`5 题` `10 题` `15 题` `20 题`（默认 10 题）

#### 第五步：错题选择（仅错题重练模式）

切换到错题重练模式后，页面展示错题选择列表：

1. 系统自动加载「学生画像 - 错题本」中的所有错题。
2. 每道错题卡片展示：
   - 学科标签（彩色区分）
   - 所属章节
   - 题目内容（最多 2 行）
   - 错因说明
   - 勾选框（默认全选）
3. 支持以下快捷操作：
   - **全选**：勾选所有错题
   - **全不选**：取消所有勾选
   - **随机 N 题**：随机选择指定数量的错题
4. 点击单道错题可切换勾选状态。

#### 第六步：开始做题

点击底部的「开始做题」按钮（错题重练模式下显示「开始练习 N 道错题」）：

- **普通练习 / 薄弱点专练**：调用 AI 出题接口（后端结合题库缓存 + AI 生成），加载完成后进入答题界面。
- **错题重练**：直接使用已选错题进入答题界面。

> 按钮在加载/生成过程中显示旋转动画和「AI 出题中...」文字。

### 6.4 答题过程（完整流程）

进入答题界面后，展示以下内容：

#### 顶部信息栏

| 元素 | 说明 |
|------|------|
| 题号 | 「第 3/10 题」形式展示当前进度 |
| 难度标签 | 简单（绿色）/ 中等（黄色）/ 困难（红色） |

## 7. 模块三：智能辅导

智能辅导模块通过与 AI 辅导员进行多轮对话，获得个性化的学习答疑和知识讲解。

### 7.1 进入智能辅导

在工作台点击「智能辅导」卡片进入。

### 7.2 界面布局

采用左右分栏布局：

- **左侧栏**：学科选择器 + 历史会话列表 + 新建会话按钮
- **右侧聊天区域**：消息列表 + 输入框

### 7.3 使用流程

1. **选择学科**：在左侧栏选择当前学习的学科
2. **新建会话**：点击「新建会话」按钮
3. **输入问题**：在底部输入框输入学习问题，按回车或点击发送
4. **查看回答**：AI 通过 SSE 流式输出实时返回回答，支持多种模态：
   - 结构化文字讲解
   - 代码块（带语法高亮）
   - 数学公式（KaTeX 渲染）
   - 流程图/概念图（Mermaid.js 渲染）
   - 知识引用标注
5. **追问深挖**：基于回答继续提问，系统自动维护上下文连贯性

### 7.4 记忆增强

系统自动从四层记忆（短期/情景/语义/实体）中检索相关内容，构建增强上下文，实现"越聊越懂你"的个性化辅导。

### 7.5 知识库检索（RAG）

当问题涉及知识库中的文档时，AI 会自动检索相关参考资料并在回答中标注来源。

## 10. 常见问题与故障排除

### Q1：系统无法启动，提示端口被占用

**解决方案**：

```bash
# 查找占用端口的进程
netstat -ano | findstr :8000
netstat -ano | findstr :3000

# 终止占用进程（替换 <PID> 为实际进程号）
taskkill /F /PID <PID>
```

或直接使用启动脚本 `启动.bat`，脚本会自动尝试释放被占用的端口。

### Q2：AI 回答不准确或答非所问

**解决方案**：

1. 在「学生画像」模块完善个人信息，画像越完整，回答越精准。
2. 明确描述问题的背景和上下文，指定学科和教材。
3. 尝试上传相关学习资料到知识库，AI 会优先检索知识库中的内容。
4. 可以要求 AI 换种方式解释，或用更具体的语言重新提问。

### Q3：资源生成速度较慢

**说明**：资源生成涉及 AI 模型调用和安全检查，每种资源类型通常需要 10-30 秒。视频和动画类型由于需要逐场景生成图片并合成，耗时更长（1-3 分钟）。

**建议**：
- 优先生成最需要的资源类型，减少同时生成的数量。
- 耐心等待，页面会实时展示生成进度。
- 生成完成后资源会保存在列表中，下次直接查看无需重新生成。

### Q4：在线做题时 AI 出题失败

**解决方案**：
1. 确认已选择学科或输入了知识点。
2. 检查 MiMo API Key 是否正确配置（`.env` 文件中的 `MIMO_API_KEY`）。
3. 减少题目数量（如从 20 题减少到 10 题）后重试。
4. 系统会优先使用题库中已缓存的题目，不足部分才调用 AI 生成。

### Q5：视频资源搜索无结果

**解决方案**：
1. 尝试使用更简短或更常见的关键词。
2. 检查网络连接是否正常。
3. 尝试使用热门搜索标签搜索。
4. 清除时长/排序筛选条件后重试。

### Q6：如何获取 MiMo API Key？

1. 访问 MiMo 开放平台：https://api.xiaomimimo.com/
2. 注册账号并登录。
3. 在控制台获取 API Key。
4. 将 Key 填入项目根目录的 `.env` 文件中 `MIMO_API_KEY` 字段。

### Q7：数据存储在哪里？

所有数据存储在本地 `data/databases/` 目录下，共 9 个独立的 SQLite 数据库文件，无需安装额外的数据库服务。

### Q8：学习数据安全吗？

- 所有数据存储在本地，不会上传到第三方服务器。
- 密码使用 bcrypt 哈希加密存储。
- 系统内置 127 条敏感词检测（AC 自动机）和内容安全审核。
- API 请求通过 JWT 令牌认证和速率限制保护（登录 10次/分钟，注册 5次/分钟）。
- HTTP 响应包含安全头（XSS 防护、Clickjacking 防护等）。

### Q9：忘记密码怎么办？

当前版本不支持密码找回功能。请联系系统管理员重置密码，或直接使用默认管理员账号 `admin` / `admin123` 登录后在用户管理中修改。

### Q10：支持移动端访问吗？

系统提供 React Native 移动端 App（基于 Expo），启动方式：

```bash
cd mobile
npm install
npx expo start
```

使用 Expo Go 扫码在真机测试，或使用 Android Studio / Xcode 模拟器运行。移动端支持工作台、智能辅导、学习资源、学生画像、学习路径、效果评估等全部功能模块。
