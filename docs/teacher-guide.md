# 教师端使用指南

> 灵犀 · 基于多智能体协作的 AI 自适应学习引擎 — 教师端完整使用说明

---

## 一、教师端概述

教师端与学生端共享同一平台，提供**班级管理**和**学情监控**两大核心能力。教师可创建班级、邀请学生加入、查看学生全维度学习数据，并使用 8 大教学功能模块。

### 功能全景

| 功能 | 说明 | 入口 |
|------|------|------|
| **教学概览** | 班级数/学生数/快捷统计 | 左侧导航 |
| **班级管理** ⭐ | 创建班级、邀请码、学生名单、移除学生 | 左侧导航 |
| **学生学情** ⭐ | 学生列表 + 11 维度下钻详情 | 左侧导航 |
| **班级学情** | 全班聚合统计 + 学生排行 | 左侧导航 |
| 学情画像 | 查看学生 9 维度画像 | 左侧导航 |
| 教学资源 | 查看学生学习资源 | 左侧导航 |
| 教学路径 | 查看学生路径进度 | 左侧导航 |
| 教学辅导 | 查看学生学习活动 | 左侧导航 |
| 班级评估 | 查看学生评估报告 | 左侧导航 |
| 题库测验 | 查看做题数据/薄弱知识点 | 左侧导航 |

> ⭐ = 老师独有功能

## 二、注册与登录

### 2.1 注册教师账号

1. 打开系统首页，切换到「注册」标签
2. **选择身份** → 「我是老师」
3. 填写用户名（3-20 字符）、密码（至少 6 位）、邮箱（可选）
4. 点击「注册账号」
5. 注册成功后自动进入**教师端工作台**

### 2.2 登录

- 已有教师账号直接登录，系统自动跳转到教师端
- 学生账号登录进入学生端

---

## 三、班级管理

### 3.1 创建班级

1. 进入「班级管理」→ 点击「创建班级」
2. 填写信息：
   - **班级名称**（必填）：如 "高一(3)班"
   - **学科**：如 "数学"
   - **年级**：如 "高一"
   - **学期**：如 "2026春"
   - **人数上限**（可选）：限制班级人数，留空不限
   - **备注**（可选）
3. 点击「创建班级」
4. 系统自动生成 **6 位邀请码**

### 3.2 邀请码管理

| 操作 | 说明 |
|------|------|
| **复制** | 一键复制邀请码到剪贴板 |
| **重置** | 生成新邀请码，旧码立即作废 |
| **关闭入班** | 禁止新学生加入（已加入的不受影响） |
| **开启入班** | 恢复允许学生加入 |

### 3.3 学生管理

- **查看名单**：进入班级详情，查看所有已加入学生
- **移除学生**：点击学生行右侧的删除按钮，确认后移除

### 3.4 学生加入方式

学生在「个人中心」→「我的班级」Tab 中输入 6 位邀请码即可加入。

## 四、学生学情查看

### 4.1 学生列表

进入「学生学情」查看所有班级的学生：
- 支持按**姓名**搜索
- 支持按**班级**筛选
- 显示学生头像、用户名、所属班级、加入时间

### 4.2 学生详情（11 个维度）

点击任意学生进入详情，可查看：

| Tab | 内容 |
|-----|------|
| **概要** | 资源数、做题数、均分、学习时长、画像评分 |
| **画像** | 9 维度学生画像详情 |
| **课程表** | 学生的课程安排 |
| **资源** | 生成/收藏的学习资源列表 |
| **路径** | 学习路径进度与完成率 |
| **做题** | 测验记录、正确率、薄弱知识点排行 |
| **评估** | 效果评估报告与总评分 |
| **学情** | 学情指标总览 |
| **活跃度** | 最近学习活动记录 |
| **错题** | 错题本（题目、错误原因、掌握状态） |
| **成绩** | 各科成绩与学分 |

### 4.3 班级学情

进入「班级学情」查看全班维度分析：
- **班级切换**：多班级下拉切换
- **聚合统计**：学生总数、平均分、资源总数、测验总数、学习时长
- **学生排行**：按均分排序，显示评分条形图

## 五、8 大教学模块

### 5.1 学情画像

- 顶部**学生选择器**选择目标学生
- 查看学生 9 维度画像（知识基础、认知风格、学习目标等）
- 无选择时提示先选择学生

### 5.2 教学资源

- 查看学生生成的学习资源列表
- 显示资源类型、学科、创建时间

### 5.3 教学路径

- 查看学生学习路径列表
- 显示进度条与完成百分比

### 5.4 教学辅导

- 查看学生学习活动记录
- 活动类型、时长、时间

### 5.5 班级评估

- 查看学生效果评估报告
- 显示评估类型、总评分、改进建议

### 5.6 题库测验

- 做题统计（测验次数、均分、薄弱点数）
- 薄弱知识点排行（按正确率升序）
- 最近测验记录

### 5.7 教学知识库

- 查看学生知识点掌握度
- 按正确率显示掌握程度条

## 六、学生侧「我的班级」

学生在**个人中心**的「我的班级」Tab 中：

| 操作 | 说明 |
|------|------|
| **加入班级** | 输入老师分享的 6 位邀请码 |
| **查看班级** | 已加入的班级列表（班级名/老师/加入时间） |
| **退出班级** | 确认后退出当前班级 |

---

## 七、数据权限说明

| 角色 | 可查看数据 | 不可查看 |
|------|-----------|----------|
| **教师** | 本班学生的全部学习数据（画像/资源/路径/做题/评估/成绩/错题/课程表） | 非本班学生的任何数据 |
| **学生** | 自己的全部学习数据 | 其他学生的数据 |
| **管理员** | 全部数据 | — |

- 所有学情代查接口均经过**师生关系校验**
- 查看非本班学生时返回 **403 权限不足**
- 数据隔离基于 `user_id`，不破坏现有隔离机制

## 八、常见问题

### Q: 忘记邀请码怎么办？
A: 在「班级管理」→ 班级详情中可随时查看当前邀请码，或点击「重置」生成新码。

### Q: 学生加入了错误的班级怎么办？
A: 在班级详情的学生名单中移除该学生，让学生重新加入正确班级。

### Q: 如何限制班级人数？
A: 创建班级时设置「人数上限」，满员后自动停止接受新学生。

### Q: 成绩和错题学生能关闭查看权限吗？
A: 当前版本成绩/错题对老师直接可见，无需学生授权（已确认的设计决策）。

### Q: 老师能看学生隐私数据吗？
A: 老师仅能查看**自己班级内**学生的学习数据，且不包含学生密码等敏感信息。
