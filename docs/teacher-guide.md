# 教师端使用指南

> 灵犀 · 基于多智能体协作的 AI 自适应学习引擎 — 教师端完整使用说明
>
> **版本**：v9.1.0

---

## 一、教师端概述

教师端与学生端共享同一平台，提供**班级管理**、**学情监控**、**AI 出题/组卷**、**主观题批改**四大核心能力。教师可创建班级、邀请学生加入、查看学生全维度学习数据，AI 一键组卷发布到班级，并对学生的主观题作答（含手写）进行 AI 辅助批改与复核。

### 功能全景

| 功能 | 说明 | 入口 |
|------|------|------|
| **教学概览** | 班级数/学生数/快捷统计 | 左侧导航 |
| **班级管理** ⭐ | 创建班级、邀请码、学生名单、移除学生 | 左侧导航 |
| **学生学情** ⭐ | 学生列表 + 11 维度下钻详情 | 左侧导航 |
| **班级学情** | 全班聚合统计 + 学生排行 | 左侧导航 |
| **AI 出题/组卷** ⭐ | AI 组卷 → 预览编辑 → 保存/导出 DOCX/发布到班级 | 左侧导航「AI出题/组卷」 |
| **批改主观题** ⭐ | 作业 → 提交 → 批改工作台 + 班级批改报告 | 左侧导航「批改主观题」 |
| 学情画像 | 查看学生 9 维度画像 | 左侧导航 |
| 教学资源 | 查看学生学习资源 | 左侧导航 |
| 教学路径 | 查看学生路径进度 | 左侧导航 |
| 教学辅导 | 查看学生学习活动 | 左侧导航 |
| 班级评估 | 查看学生评估报告 | 左侧导航 |
| 题库测验 | 查看做题数据/薄弱知识点 | 左侧导航 |

> ⭐ = 老师独有功能

## 二、注册与登录

### 2.1 注册教师账号

1. 打开系统首页，切换到「注册」标签
2. **选择身份** → 「我是老师」
3. 填写用户名（3-20 字符）、密码（至少 6 位）、邮箱（可选）
4. 点击「注册账号」
5. 注册成功后自动进入**教师端工作台**

### 2.2 登录

- 已有教师账号直接登录，系统自动跳转到教师端
- 学生账号登录进入学生端

## 三、班级管理

### 3.1 创建班级

1. 进入「班级管理」→ 点击「创建班级」
2. 填写信息：
   - **班级名称**（必填）：如 "高一(3)班"
   - **学科**：如 "数学"
   - **年级**：如 "高一"
   - **学期**：如 "2026春"
   - **人数上限**（可选）：限制班级人数，留空不限
   - **备注**（可选）
3. 点击「创建班级」
4. 系统自动生成 **6 位邀请码**

### 3.2 邀请码管理

| 操作 | 说明 |
|------|------|
| **复制** | 一键复制邀请码到剪贴板 |
| **重置** | 生成新邀请码，旧码立即作废 |
| **关闭入班** | 禁止新学生加入（已加入的不受影响） |
| **开启入班** | 恢复允许学生加入 |

### 3.3 学生管理

- **查看名单**：进入班级详情，查看所有已加入学生
- **移除学生**：点击学生行右侧的删除按钮，确认后移除

### 3.4 学生加入方式

学生在「个人中心」→「我的班级」Tab 中输入 6 位邀请码即可加入。

### 4.1 学生列表

| **画像** | 9 维度学生画像详情 |
| **课程表** | 学生的课程安排 |
| **资源** | 生成/收藏的学习资源列表 |
| **路径** | 学习路径进度与完成率 |
| **做题** | 测验记录、正确率、薄弱知识点排行 |
| **评估** | 效果评估报告与总评分 |
| **学情** | 学情指标总览 |
| **活跃度** | 最近学习活动记录 |
| **错题** | 错题本（题目、错误原因、掌握状态） |
| **成绩** | 各科成绩与学分 |

### 4.3 班级学情

进入「班级学情」查看全班维度分析：
- **班级切换**：多班级下拉切换
- **聚合统计**：学生总数、平均分、资源总数、测验总数、学习时长

## 六、AI 出题/组卷（v9.1.0 新增）

入口：左侧导航「**AI出题/组卷**」（`ExamPaperView`），3 个 Tab：**生成 → 预览编辑 → 管理**。

### 6.1 AI 生成试卷

1. 填写命题要求：
   - **学科 / 年级 / 主题**（如 数据结构 / 大一 / 二叉树）
   - **知识点**（可多个，如「二叉树遍历」「平衡树」）
   - **难度**：基础 / 中等 / 较难 / 难易混合
   - **卷型**：练习卷 / 考试卷
   - **总分 / 考试时长**
   - **题型数量**：选择题 / 判断题 / 填空题 / 简答题（默认 5 / 3 / 3 / 2）
   - **题库复用**：开启后最多 50% 题目来自已有题库，其余由 AI 新生成
2. 点击「AI 生成」→ 系统从 **RAG 知识库取材** + 题库复用 + LLM 生成，并按题型权重折算每题分值（合计=总分）
3. 生成结果为**预览**，不自动保存；LLM 失败时自动兜底模板题

### 6.2 预览编辑

- 逐题查看/编辑题干、选项、正确答案、参考答案、评分要点、解析、知识点、分值
- 可增删题目、调整顺序与分值
- 满意后「保存试卷」入库

### 6.3 管理（保存 / 导出 / 发布）

| 操作 | 说明 |
|------|------|
| **保存试卷** | 保存到「我的试卷」，可再次编辑 |
| **导出 DOCX** | 生成可打印试卷：试题卷 + 答案解析分页，下载到本地 |
| **发布到班级** | 选择班级、设置截止时间与是否允许补交，学生即可在「班级作业」中看到 |

## 七、批改主观题（v9.1.0 新增）

入口：左侧导航「**批改主观题**」（`GradingView`），流程：**选作业 → 选提交 → 批改工作台**，并可查看**班级报告**。

### 7.1 学生如何交卷

学生在个人中心「**班级作业**」Tab 中：查看作业 → 文本作答 和/或 **上传手写答案图片** → 交卷。
上传手写图后系统自动 OCR 识别，识别文本可由学生/老师修正后再批改。

### 7.2 批改工作台

1. 选择某次作业 → 提交列表（显示批改进度：待批改 / AI 已批改 / 教师已复核）
2. 进入某份提交，逐题批改：

| 题型 | 判分方式 |
|------|---------|
| 选择 / 判断 / 填空 | **自动判分**，即时出分 |
| 简答（主观题） | **AI 辅助批改**，教师可复核 |

**主观题 AI 批改链路**：

```
手写图 → 手写识别（RapidOCR 主力 + 视觉模型兜底）
      → RAG 知识库检索评分依据（rag_evidence）
      → LLM 评分：分数 + 评语 + 知识点命中/缺失 + 改进建议
      → 关键词兜底（LLM 不可用时）
      → 教师复核改分（最终成绩以教师为准）
```

3. **教师复核**：对 AI 评分可直接改分、补充评语；保存后 `grade_status` 变为「教师已复核」，最终成绩以教师为准
4. **整卷批改**：一键 AI 批改整份提交（客观题自动判分 + 主观题逐题 AI 评分）

### 7.3 班级批改报告

在作业详情页查看班级报告：

- **得分分布**：各分数段人数
- **逐题统计**：每题均分 / 得分率
- **薄弱知识点**：全班失分集中的知识点
- **排名**：学生总分排行

可据此调整教学重点。

## 九、数据权限说明

| 角色 | 可查看数据 | 不可查看 |
|------|-----------|----------|
| **教师** | 本班学生的全部学习数据（画像/资源/路径/做题/评估/成绩/错题/课程表/考试作答与手写图） | 非本班学生的任何数据 |
| **学生** | 自己的全部学习数据、自己班级的作业题目（不含答案） | 其他学生的数据、试题答案与评分要点 |
| **管理员** | 全部数据 | — |

- 所有学情代查接口均经过**师生关系校验**
- 查看非本班学生时返回 **403 权限不足**
- 数据隔离基于 `user_id`，不破坏现有隔离机制
- **手写答案图片**（`GET /api/exam/answers/{id}/image`）同样走权限校验：仅提交本人、任课教师或管理员可访问
- 学生获取作业题目时自动**脱敏**，不含正确答案 / 参考答案 / 评分要点

## 十、常见问题

### Q: 忘记邀请码怎么办？
A: 在「班级管理」→ 班级详情中可随时查看当前邀请码，或点击「重置」生成新码。

### Q: 学生加入了错误的班级怎么办？
A: 在班级详情的学生名单中移除该学生，让学生重新加入正确班级。

### Q: 如何限制班级人数？
A: 创建班级时设置「人数上限」，满员后自动停止接受新学生。

### Q: 成绩和错题学生能关闭查看权限吗？
A: 当前版本成绩/错题对老师直接可见，无需学生授权（已确认的设计决策）。

### Q: 老师能看学生隐私数据吗？
A: 老师仅能查看**自己班级内**学生的学习数据，且不包含学生密码等敏感信息。

### Q: AI 生成的题目可以直接用吗？
A: 生成结果为**预览**，请在「预览编辑」中人工审核后再保存/发布。AI 会从 RAG 知识库取材并复用题库（≤50%），LLM 失败时自动兜底模板题。

### Q: 学生手写答案识别不准怎么办？
A: 批改前可在作答文本框中手动修正 OCR 文本（`PUT /api/exam/answers/{id}`）。识别置信度低于 0.55 时系统会自动改用视觉模型二次识别，仍不准则请人工修正。

### Q: AI 批改的分数能改吗？
A: 可以。教师复核改分后**最终成绩以教师为准**，状态变为「教师已复核」。

### Q: 如何导出可打印试卷？
A: 在「AI出题/组卷」→ 管理中点「导出 DOCX」，生成试题卷 + 答案解析分页的 Word 文件后下载。
